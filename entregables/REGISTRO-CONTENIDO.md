## 6. CÓMO GENERAR LAS TARJETAS

Script de referencia: el usado en `scratchpad/tarjetas-s4.py` (efímero; si no existe,
recrear con este patrón). Genera JPG con la identidad "El punto":

- **LinkedIn:** 1200x628, fondo papel `#F5F3EB` o noche `#071233`
- **Instagram:** 1080x1350 (4:5), mismo sistema
- Tipografía Archivo (títulos, `font-stretch:118%`) + Chivo Mono (kicker y marca)
- Azul `#2C03F3` sobre papel · Azul claro `#76C1FF` sobre noche
- Estructura: kicker arriba · titular grande con punto final en color · lista opcional
  numerada `01 02 03` · pie con botón CTA y `victormago.com`

Las tarjetas se guardan en `public/ig/`, se despliegan con
`git push` + `npx vercel deploy --prod --yes`, y se inyectan en Buffer con este JS
(el file picker nativo no es accesible):

```js
const input = document.querySelector('[role="dialog"] input[type="file"]');
const r = await fetch('https://victormago.com/ig/NOMBRE.jpg');
const b = await r.blob();
const dt = new DataTransfer();
dt.items.add(new File([b], 'NOMBRE.jpg', { type: 'image/jpeg' }));
input.files = dt.files;
input.dispatchEvent(new Event('change', { bubbles: true }));
```

Requiere CORS abierto en `/ig/*` (ya configurado en `next.config.ts`).

## 7. TRAMPAS CONOCIDAS DE BUFFER

- **El editor rechaza los acentos** cuando el entorno se degrada: los envía amontonados
  al principio del texto ("ññíñíóñ..."). Si pasa: cerrar la pestaña y abrir una NUEVA
  (recargar no basta). Si aun así falla, escribir el texto SIN tildes y avisar a Víctor
  para que las repase, o dejarlo preparado en el pack para que él lo pegue.
- **El composer se queda en blanco** tras varias operaciones seguidas. Misma solución:
  pestaña nueva.
- **El date picker registra el clic en otra fila.** Verificar SIEMPRE la fecha del botón
  inferior antes de Schedule.
- **El selector de canal recuerda el último usado.** Comprobar el preview (dice
  "LinkedIn Preview" o "Instagram Preview") antes de escribir.
- Atajo: el botón "New post" del canal en la barra lateral preselecciona ese canal.
